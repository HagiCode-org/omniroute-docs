## 本轮改动

- 术语表与上游现有中文对齐（provider=提供者、authentication=身份验证、token=令牌、dashboard=仪表板、agent=智能体等），共 70 条；新增 `avoid` 禁用译法字段和产品名原样保留条目（Combo、Claude Code 等）。较长的词优先匹配，不再重复选中 `key`、`token`。
- 新增 `scripts/translate-document-ollama.mjs`：按块拆分、约 300 词分块、大表格按行拆分并重复表头、3 个种子重试、逐块回退、仍失败则保留英文并记录。徽章图、代码块和纯标记块（国旗图标、贡献者链接表）不发给模型。
- 新增 `scripts/evaluate-translated-document.mjs`：整文结构检查、术语落地、禁用译法、仍为英文的正文块，并与上游译文对照。
- 修复保护器漏洞：`<code>…</code>` 内的文字原先没有被保护，`release/v3.8.50` 被译成“版本/v3.8.50”。现已整段保护并加测试。

## 语义抽查

在 137 个部分中按固定间隔抽了 11 个，与英文逐句对照（不是随机抽样，也没有第二位评审）：

- **可作待校对初稿（6–7 个）**：赞助说明、`Compatible CLIs` 标题块、Auto-Combo 说明、文档链接行、Docker 指南引用、葡萄牙语排名标题；提供者统计段落意思基本正确，但有“位注册提供者”“按设计设定”等生硬用法。
- **有实质错误（4 个）**：
  - 免费额度概述：`positive monthly budget` 被译成“公开正月预算”，开头“手动手动”重复，`credit tiers` 被译成“信用层级”，“还需额外约 600 万”误解了 `+~6M behind regional identity verification`。
  - OmniGlyph 表格行：`measured Claude Fable 5` 译成“测量后的”，`fail-closed` 译成“故障封闭”。
  - 贡献统计脚注：`Ties at the cutoff are retained` 被译成“截止日期之前的链接则被保留”，`churn` 译成“动态变化”，修复保护器之前还把 `release` 译了。（修复后这个块三次都未通过校验，保留了英文。）

这与上一轮 14 组样本中 8 组可作初稿的结果相近，不能说明语义质量有提升。术语一致性和结构保真有改善，语义错误没有被术语表解决。

## 局限与后续

- 重试用换种子的办法，3 次都丢标记的块只能保留英文；这类块可以改为按行拆分，或把 HTML 表格改为专门的单元格级翻译。
