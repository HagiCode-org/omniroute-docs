# Flaggensymbole

SVG-Länderflaggen, die vom Sprachauswähler im Root-`README.md` verwendet werden.

Sie werden lokal ausgeliefert (statt als Unicode-Flaggen-Emoji), weil Regional-Indicator-
Flaggen-Emoji unter Windows und mehreren Safari/WebKit-Konfigurationen **nicht** dargestellt
werden, wodurch die Tabelle "In 43 languages" auf diesen Plattformen kaputtging.

## Quelle und Lizenz

Die Flaggen stammen von [lipis/flag-icons](https://github.com/lipis/flag-icons)
(`flags/4x3/`) und stehen unter der **MIT**-Lizenz. Jede Datei ist nach ihrem
ISO-3166-1-alpha-2-Ländercode benannt (z. B. `br.svg`, `us.svg`). Die sechs Zellen für indische Sprachen (`in`, `hi`,
`gu`, `mr`, `ta`, `te`) verwenden gemeinsam die eine Datei `in.svg`.
