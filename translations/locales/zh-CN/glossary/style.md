# style.md — zh-CN 风格笔记

## 起始规则
- 源文档的语气与人称保持一致;技术文档用书面、克制的语气。
- 列表与表格的句末标点跟随源文档。
- `Yes`/`No`、`Enabled`/`Disabled` 等固定状态词在整个站点内统一译法(进术语表)。
- 全角标点;中英文与数字之间加一个半角空格;读者称"你",不称"您"。
- 英文单词、代码、命令、配置键与产品名保持原写法。
- 明显的技术单词(如 `gate`、`quality-gate`)保留原文,任何语言都不翻译(人工裁决,2026-10-30);与中文之间按"中英文加半角空格"处理,例如"质量 gate 脚本"。拿不准是不是"明显的技术词"时,优先看它是否已在 `doNotTranslate` 或属于行业通行的英文术语。
