# style.md — zh-CN 风格笔记

## 起始规则
- 源文档的语气与人称保持一致;技术文档用书面、克制的语气。
- 列表与表格的句末标点跟随源文档。
- `Yes`/`No`、`Enabled`/`Disabled` 等固定状态词在整个站点内统一译法(进术语表)。
- 全角标点;中英文与数字之间加一个半角空格;读者称"你",不称"您"。
- 英文单词、代码、命令、配置键与产品名保持原写法。
- 明显的技术单词保留原文,任何语言都不翻译(人工裁决,2026-10-30)。范围:通行的工程术语(如 `gate`、`proxy`、`endpoint`、`prompt`、`fallback`、`cooldown`、`agent`、`self-hosted`、`Hard Rule`)、产品名与平台名;完整清单见术语表(`origin: human`)与 `doNotTranslate`。与中文之间加半角空格,例如“质量 gate 脚本”“自托管的 proxy”。仍可翻译的普通词(如 Context、Provider、combo)不在此列。拿不准时,看它是否已在 `doNotTranslate` 或属于开发者日常直接说英文的词。
