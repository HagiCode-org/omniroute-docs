# 旗帜图标

用于根目录 `README.md` 中语言选择器的 SVG 国家旗帜。

这些旗帜以本地文件的形式提供，而不使用 Unicode 旗帜表情符号，因为区域指示符旗帜表情符号在 Windows 以及部分 Safari/WebKit 配置中无法正常显示，会导致这些平台上的“In 43 languages”表格显示异常。

## 来源与许可

旗帜图片来自 [lipis/flag-icons](https://github.com/lipis/flag-icons)（`flags/4x3/`），采用 **MIT** 许可证。每个文件均以 ISO 3166-1 alpha-2 国家代码命名（例如 `br.svg`、`us.svg`）。六个印度语言单元格（`in`、`hi`、`gu`、`mr`、`ta`、`te`）共用同一个 `in.svg`。
