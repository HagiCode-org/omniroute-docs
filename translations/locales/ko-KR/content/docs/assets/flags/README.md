# 국기 아이콘

루트 `README.md`의 언어 선택기에서 사용하는 SVG 국가 국기입니다.

유니코드 국기 이모지 대신 로컬에서 제공하는 이유는, 지역 표시 기호(regional indicator) 국기 이모지가 Windows와 일부 Safari/WebKit 구성에서 **렌더링되지 않아** 해당 플랫폼에서 "43개 언어" 표가 깨졌기 때문입니다.

## 출처 및 라이선스

국기는 [lipis/flag-icons](https://github.com/lipis/flag-icons)(`flags/4x3/`)에서 가져온 것이며 **MIT** 라이선스입니다. 각 파일은 ISO 3166-1 alpha-2 국가 코드로 이름이 지정되어 있습니다(예: `br.svg`, `us.svg`). 인도 언어 셀 여섯 개(`in`, `hi`, `gu`, `mr`, `ta`, `te`)는 하나의 `in.svg`를 함께 사용합니다.
