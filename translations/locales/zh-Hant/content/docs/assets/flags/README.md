# 旗幟圖示

用於根目錄 `README.md` 中語言選擇器的 SVG 國家旗幟。

這些旗幟以本機檔案的形式提供，而不使用 Unicode 旗幟表情符號，因為區域指示符旗幟表情符號在 Windows 以及部分 Safari/WebKit 設定中無法正常顯示，會導致這些平台上的「In 43 languages」表格顯示異常。

## 來源與授權

旗幟圖片來自 [lipis/flag-icons](https://github.com/lipis/flag-icons)（`flags/4x3/`），採用 **MIT** 授權條款。每個檔案均以 ISO 3166-1 alpha-2 國家代碼命名（例如 `br.svg`、`us.svg`）。六個印度語言儲存格（`in`、`hi`、`gu`、`mr`、`ta`、`te`）共用同一個 `in.svg`。
