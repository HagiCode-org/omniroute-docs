# CLI Companion

Dashboard CLI Code включает companion только для копирования для исполняемых
целей CLI, поддерживаемых этой версией OmniRoute. Он не запускает процесс, не записывает
конфигурацию, не тестирует инференс и не отправляет учётные данные в clipboard.

## Обнаружение на сервере — это не обнаружение в браузере

Статусы обнаружения, среды выполнения и конфигурации описывают машину, на которой работает
сервер OmniRoute. Если вы открываете удалённый dashboard с ноутбука, отсутствие CLI
на этом сервере ничего не говорит о CLI, установленном на вашем ноутбуке. Неизвестный и
неудавшийся результат обнаружения остаются явными; они не считаются «не установлен». Необработанные
диагностические ошибки и endpoints конфигурации в этой панели не показываются.

Копируйте команды в терминал той машины, на которой вы хотите использовать CLI.
Companion не блокирует локальные инструкции, когда обнаружение на сервере завершается неудачей.

## Локальные или удалённые контексты

Начните с просмотра контекстов, уже настроенных в вашем терминале:

```sh
omniroute contexts list
omniroute contexts current
```

Оставьте поле контекста в companion пустым, чтобы использовать активный контекст CLI, или
введите имя существующего контекста. Именованный контекст может указывать на локальный или удалённый
сервер. Dashboard не читает хранилище контекстов вашего терминала, не создаёт
контекст и не копирует его учётные данные. Например, если `office` уже существует:

```sh
omniroute configure claude --context office
omniroute run claude --context office --dry-run
```

`configure` интерактивна и записывает конфигурацию на той машине, где вы
её выполняете. `run --dry-run` показывает план запуска, не запуская целевую программу;
он не подтверждает, что upstream-инференс работает. Пройдите аутентификацию в терминале
с помощью существующего процесса работы с контекстами CLI, прежде чем выполнять эти команды.

Предлагаются только возможности, объявленные в исполняемом manifest. Если цель
требует модель, её команда запуска остаётся недоступной, пока вы не укажете реальный
идентификатор модели. Поля контекста/модели принимают ограниченный набор буквальных символов;
операторы оболочки, пробелы и ведущий синтаксис опций отклоняются.

Если доступ к clipboard завершается неудачей, панель сообщает об ошибке и оставляет команду
видимой для ручного выделения. Копирование никогда не выполняет её.

## Граница реализации

Загрузчик только для сервера в `src/lib/cli-helper/companionTargets.ts` проецирует
исполняемый manifest в публичные дескрипторы. Браузер получает только ID целей,
отображаемые имена и флаги возможностей, а не модули Node и не секреты среды выполнения.
Проверка команд и сопоставление статусов находятся в `src/shared/utils/cliCompanion.ts`.
Панель повторно использует существующий запрос пакетного статуса dashboard; она не вводит
API выполнения и дополнительный опрос статуса.
