# Иконки флагов

SVG-флаги стран, используемые в переключателе языка в корневом `README.md`.

Они отдаются локально (вместо Unicode-эмодзи флагов), потому что эмодзи флагов на основе региональных индикаторов
**не** отображаются в Windows и в ряде конфигураций Safari/WebKit, из-за чего на этих платформах
ломалась таблица «На 43 языках».

## Источник и лицензия

Флаги взяты из [lipis/flag-icons](https://github.com/lipis/flag-icons)
(`flags/4x3/`) и распространяются по лицензии **MIT**. Каждый файл назван по двухбуквенному коду страны
ISO 3166-1 alpha-2 (например, `br.svg`, `us.svg`). Шесть ячеек для индийских языков (`in`, `hi`,
`gu`, `mr`, `ta`, `te`) используют один и тот же файл `in.svg`.
