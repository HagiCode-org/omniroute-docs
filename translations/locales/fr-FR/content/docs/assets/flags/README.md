# Icônes de drapeaux

Drapeaux de pays au format SVG utilisés par le sélecteur de langue du `README.md` racine.

Ils sont servis localement (au lieu des emoji de drapeaux Unicode) car les emoji de drapeaux
à indicateurs régionaux ne s'affichent **pas** sous Windows ni dans plusieurs configurations
de Safari/WebKit, ce qui cassait le tableau "Dans 43 langues" sur ces plateformes.

## Source et licence

Les drapeaux proviennent de [lipis/flag-icons](https://github.com/lipis/flag-icons)
(`flags/4x3/`), sous licence **MIT**. Chaque fichier porte le nom du code pays ISO 3166-1
alpha-2 (par exemple `br.svg`, `us.svg`). Les six cellules de langues indiennes (`in`, `hi`,
`gu`, `mr`, `ta`, `te`) réutilisent l'unique `in.svg`.
