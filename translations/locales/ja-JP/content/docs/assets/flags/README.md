# 国旗アイコン

ルートの `README.md` にある言語セレクターで使われる、SVG 形式の国旗です。

Unicode の国旗絵文字ではなくローカルのファイルとして提供しているのは、地域指示記号による
国旗絵文字が Windows や一部の Safari/WebKit 構成では**表示されず**、それらのプラットフォームで
「In 43 languages」の表が崩れていたためです。

## 出典とライセンス

国旗は [lipis/flag-icons](https://github.com/lipis/flag-icons)
（`flags/4x3/`）のもので、ライセンスは **MIT** です。各ファイルの名前は ISO 3166-1 alpha-2 の
国コードです（例：`br.svg`、`us.svg`）。インド系言語の 6つのセル（`in`、`hi`、
`gu`、`mr`、`ta`、`te`）は、1つの `in.svg` を共用しています。
