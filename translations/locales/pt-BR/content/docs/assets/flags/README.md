# Ícones de bandeira

Bandeiras de países em SVG usadas pelo seletor de idioma no `README.md` da raiz.

Elas são servidas localmente (em vez de emoji Unicode de bandeira) porque os emoji
de bandeira com indicadores regionais **não** são renderizados no Windows nem em
várias configurações do Safari/WebKit, o que quebrava a tabela "Em 43 idiomas" nessas plataformas.

## Fonte e licença

As bandeiras vêm de [lipis/flag-icons](https://github.com/lipis/flag-icons)
(`flags/4x3/`), licenciadas sob **MIT**. Cada arquivo é nomeado pelo código de país
ISO 3166-1 alpha-2 (por exemplo, `br.svg`, `us.svg`). As seis células de idiomas indianos (`in`, `hi`,
`gu`, `mr`, `ta`, `te`) reutilizam o único `in.svg`.
