# Iconos de banderas

Banderas de países en SVG utilizadas por el selector de idioma del `README.md` raíz.

Se sirven de forma local (en lugar de emoji de banderas Unicode) porque los emoji de
banderas basados en indicadores regionales **no** se muestran en Windows ni en varias
configuraciones de Safari/WebKit, lo que rompía la tabla "En 43 idiomas" en esas plataformas.

## Origen y licencia

Las banderas proceden de [lipis/flag-icons](https://github.com/lipis/flag-icons)
(`flags/4x3/`) y se distribuyen bajo licencia **MIT**. Cada archivo se nombra con el código
de país ISO 3166-1 alfa-2 (por ejemplo, `br.svg`, `us.svg`). Las seis celdas de idiomas de la India (`in`, `hi`,
`gu`, `mr`, `ta`, `te`) reutilizan el único archivo `in.svg`.
