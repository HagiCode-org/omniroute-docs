# OmniRoute documentation

[![last commit](https://img.shields.io/github/last-commit/HagiCode-org/omniroute-docs)](https://github.com/HagiCode-org/omniroute-docs/commits/main)
[![website](https://img.shields.io/website?url=https%3A%2F%2Fomniroute.hagicode.com&label=website)](https://omniroute.hagicode.com)

OmniRoute Docs is the documentation site for [OmniRoute](https://github.com/diegosouzapw/OmniRoute), the AI gateway that routes models and providers. Read it at **[omniroute.hagicode.com](https://omniroute.hagicode.com)**.

## What you can read

The site publishes the upstream OmniRoute guides, reference and architecture documents, organized in the same reading areas as the project's own documentation:

- Getting started: quick start and self-hosting
- Guides: user guide and other task-oriented guides
- Architecture: how the gateway is designed
- Reference, providers, routing, security and operations documents

## Languages

The site is available in ten languages: Simplified Chinese, English, Traditional Chinese, Japanese, Korean, German, French, Spanish, Brazilian Portuguese and Russian. Use the language selector to switch. Where a page has no translation yet, the site shows the English page with a clearly marked English fallback notice.

## RSS feeds

Subscribe to be notified of new documentation:

- English: `https://omniroute.hagicode.com/rss.xml`
- Other languages: `https://omniroute.hagicode.com/rss.<locale>.xml` (for example, `https://omniroute.hagicode.com/rss.zh-CN.xml`)

Localized feeds do not include English fallback pages.
